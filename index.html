Awesome Open-Source Rust Apps

This list curates open-source applications and tools built with Rust, including cross-platform desktop apps and other useful projects.

Contributions are welcome via PR, and I will feature your app on my social media account (𝕏).

Tools & Utilities

  • RustFS - Distributed S3-compatible object storage.
  • Shuffle - A GPU-accelerated file manager and Finder alternative.
  • Look - Keyboard-first desktop launcher with offline search.
  • Git Agent - A cross-platform native Git client.
  • klipa - A small, fast, cross-platform menu bar clipboard manager.
  • Day-Monitor - An AI-powered activity tracker that automatically creates visual daily work reports.
  • Lap - Local photo manager with AI search and media support.
  • SideX - A lightweight, cross-platform VS Code alternative.
  • FluxDown - Multi-protocol downloader for HTTP, BitTorrent, ED2K, and streaming.
  • Zephyr - A cross-platform Mihomo (Clash Meta) desktop proxy client.
  • OpenTypeless - A cross-platform desktop tool for global AI voice input.
  • RustCast - Fast launcher for apps, tools, and workflows.
  • 青简 Qingjian - Cross-platform pinyin input method with inline translations for language learning.
  • NeoHtop - A lightweight cross-platform system monitor with process management.
  • todofy - Task manager with smart lists, recurring tasks, Pomodoro, reminders, and tray support.
  • Wu - A fast, lightweight native code editor focused on core editing.
  • OpenLogi - Open-source Logitech mouse configurator for buttons, DPI, and SmartShift.

Graphics & Design

  • Gridvana - Pixel art and animation editor for human-AI collaboration.
  • Kiri - A local screenshot, annotation, OCR, and screen recording tool.

Video & Audio

  • OpenCut - An open-source, cross-platform video editor and CapCut alternative.
  • Sonora - A music player with support for Spotify and YouTube Music.
  • Soufflé - A local dictation and meeting transcription tool with speaker diarization and AI summaries.
  • Fastpotify - A cross-platform Spotify client.

AI & Machine Learning

  • Kitter - A lightweight AI skill management tool.
  • Metis - An open-source AI coding agent tool.
  • Claude Buddy - A macOS floating widget for monitoring multiple Claude Code sessions.
  • Claudebar - A cross-platform app for viewing your Claude usage limits.
  • Wenlan - An open-source, local-first, traceable AI knowledge base for coding agents.
  • Higgs - A local MLX model runner with OpenAI and Anthropic-compatible APIs, multi-provider routing, and a dashboard.
  • Ferrox - A native inference engine and drop-in alternative to llama.cpp.
  • Waku - A high-performance native desktop client for managing multiple AI coding agent CLIs.
  • DSH Studio - A cross-platform desktop application for working with DeepSeek.
  • Vibe Observer - A macOS app for tracking Claude Code token usage, costs, and session spending.
  • Wake - A native macOS app for organizing and searching coding agent sessions.
