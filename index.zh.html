精选 Rust 开源应用

本列表收集使用 Rust 构建的开源应用和工具，涵盖跨平台桌面应用及其他实用项目。

欢迎通过 PR 提交你的开源项目，我会在我的社交媒体账号 (𝕏) 上推荐你的应用。

工具与实用程序

  • RustFS - 分布式 S3 兼容对象存储。
  • Shuffle - GPU 加速的文件管理器，Finder 的替代品。
  • Look - 键盘优先的桌面启动器，支持离线搜索。
  • Git Agent - 跨平台原生 Git 客户端。
  • klipa - 小巧快速的跨平台菜单栏剪贴板管理器。
  • Day-Monitor - AI 驱动的活动追踪工具，可自动生成可视化的每日工作报告。
  • Lap - 支持 AI 搜索的本地照片管理器，兼容 RAW 和视频。
  • SideX - 轻量、跨平台的 VS Code 替代编辑器。
  • FluxDown - 支持 HTTP、BT、ED2K 和流媒体的下载工具。
  • Zephyr - 跨平台的 Mihomo（Clash Meta）桌面代理客户端。
  • Clash Verge - 跨平台的 Clash Meta 图形化客户端，支持 Windows、macOS 和 Linux。
  • SparkleBIOS - 为每个终端标签页加上趣味复古的 1995 年 PC BIOS 启动界面。
  • PinkDown - 原生双栏 Markdown 编辑阅读器，启动迅捷、界面精致。
  • OpenTypeless - 跨平台的全局 AI 语音输入桌面工具。
  • RustCast - 快速启动应用、工具并管理工作流。
  • NeoHtop - 轻量的跨平台系统监视器，支持进程管理。
  • todofy - 支持智能列表、循环任务、番茄钟和提醒的跨平台待办应用。
  • DayApp - macOS 原生的今日待办清单，自动记录你的每个操作，让日志自己写完。
  • Wu - 快速轻量、专注核心编辑功能的原生代码编辑器。
  • OpenLogi - 开源的 Logitech 鼠标配置工具，支持按键、DPI 和 SmartShift 设置。
  • sbtfix - macOS 菜单栏应用，通过蓝牙直接控制索尼耳机的降噪与电量。
  • Flectar Mail - 支持离线使用的邮件、日历和联系人管理客户端。
  • Combe - 带 worktree 目录的 macOS 原生终端。
  • buffTerm - AI 驱动的桌面 SSH 管理工具，支持通过自然语言管理服务器。
  • con - 内置终端原生 AI 执行框架的 GPU 加速终端模拟器。
  • tty7 - 终端工作台，支持持久会话、SSH 远程办公与编程智能体。
  • Mado - macOS 终端复用器，采用侧边栏插件架构。
  • LumeTrace - 专注于快速高效文件浏览的开源 macOS 文件管理器。
  • HopToDesk - 免费的远程访问平台，用于连接和管理设备。
  • workbuddy-switch - 一键切换 WorkBuddy/CodeBuddy 登录账号的桌面应用，支持积分监控与自动签到。
  • smabar - 屏幕边缘的应用停靠栏，可固定应用、文件与网站，并支持插件扩展。
  • Rift - macOS 平铺式窗口管理器，专注于性能与易用性。
  • Winlane - macOS 菜单栏启动器，融合窗口切换与应用、剪贴板、片段搜索。
  • Recall - 剪贴板管理器，支持语义搜索，并自动排除凭证类敏感内容。
  • Markview - 快速的原生 Markdown 阅读器，具备出版级排版，无需浏览器或 WebView 即可渲染数学公式、代码与表格。

输入法

  • 青简 Qingjian - 带候选词译文的跨平台拼音输入法。
  • 微明 Glimmer - 跨平台输入法。

图形与设计

  • Gridvana - 支持人机协同创作的像素画与动画编辑器。
  • Kiri - 跨平台截图、标注、OCR 与区域录制工具。
  • PixelSlim - 轻量的 macOS 批量图片压缩与格式转换工具。

视频与音频

  • OpenCut - 开源的跨平台视频编辑器，CapCut 的替代方案。
  • Sonora - 支持 Spotify 和 YouTube Music 的音乐播放器。
  • Soufflé - 本地听写与会议转录工具，支持说话人分离和 AI 摘要。
  • mimi - 支持 macOS 和 Windows 的系统音频实时字幕与翻译工具，适用于视频、会议和游戏。
  • Fastpotify - 跨平台 Spotify 客户端。
  • EKO - 原生 macOS 音乐客户端，支持 Navidrome/Subsonic 与本地音乐文件。
  • VocalCode Community - 本地优先的听写与会议记录工具，支持 Windows 和 macOS。

AI 与机器学习

  • Kitter - 轻量的 AI Skill 管理工具。
  • Metis - 开源的 AI 编程 Agent 工具。
  • hippoxOS - 以自然语言为核心交互方式的 AI 原生桌面操作系统。
  • Claude Buddy - macOS 悬浮小组件，用于监控多个 Claude Code 会话状态。
  • Claudebar - 用于查看 Claude 使用限额的跨平台应用。
  • Wenlan - 面向编程智能体的开源、本地优先、来源可追溯的 AI 知识库。
  • Higgs - 本地 MLX 模型服务，支持兼容 API 和多提供商路由。
  • Ferrox - llama.cpp 的原生推理引擎替代方案。
  • Waku - 用于统一管理多款 AI 编码 Agent CLI 的高性能原生桌面客户端。
  • DSH Studio - 用于使用 DeepSeek 的跨平台桌面应用。
  • Vibe Observer - 用于分析 Claude Code token 使用量、成本和会话开销的 macOS 应用。
  • Wake - 用于整理和搜索编码 Agent 会话的原生 macOS 应用。
  • Codex Quota Dot - 轻量的悬浮小组件，实时显示 Codex CLI/Desktop 的配额、限额与重置时间。
  • OpenHuman - 开源的智能体运行框架，具备本地优先记忆、智能体编排与工作流能力。
  • PI-Desktop - 模块化、本地优先的桌面工作区，统一管理项目、智能体、模型与工作流。
  • Screenpipe - 本地持续录制屏幕，并为 AI 智能体提供工作上下文。
  • PinkCode - Grok Build 的桌面图形客户端，可视化任务进度、积分与 token 用量。
